# hermes-plugins-collection

Public mirror of the Hermes plugin collection. Each plugin is a standalone repository under
[`nnnet/hermes-plugin-*`](https://github.com/orgs/nnnet/repositories?q=hermes-plugin-&type=all&language=&sort=name) and is consumed by the Hermes runtime as a git submodule.

## Sub-plugins

See [`.gitmodules`](./.gitmodules) for the canonical list. Browse them on GitHub:
[plugins under `nnnet/hermes-plugin-*`](https://github.com/orgs/nnnet/repositories?q=hermes-plugin-&type=all&language=&sort=name).

Related: [`hermes-skills-collection`](https://github.com/nnnet/hermes-skills-collection) — the matching skill super-repo.

## Public status

This collection is public as of **2026-09-06**. All sub-repositories are public.
URLs in `.gitmodules` use `https://` so anonymous clones can resolve submodules without deploy keys.
